# Sistema de Cadastro de Alunos

Projeto desenvolvido para praticar os fundamentos de Python

## Funcionalidades

- Adicionar pessoa
- Remover pessoa
- Listar pessoas
- Buscar pessoa
- Calcular IMC
- Atualzar dados de aluno
- Mostrar estatísticas

## Tecnologia

- Python 3.12.9

## Como executar

python src/main.py
